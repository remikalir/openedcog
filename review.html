OpenedCog: verbal item review

This page lists every item in the three picture-based (verbal) subtests. Each item shows its pictures, the four answer choices with the correct one outlined in green, and the explanation a child hears after answering in learning mode. The number, bead, shape, and paper-folding puzzles aren't listed because the site generates those fresh each time.

What to look for

  • One right answer. Could a thoughtful child defend a different choice? If so, the item needs fixing.
  • Clear pictures. Would a seven-year-old recognize each picture as what the item intends?
  • Fair to every child. Does the item assume knowledge some families wouldn't have, such as a region, climate, holiday, food, or experience?
  • Plain words. Are the spoken question and the explanation easy to follow when heard, not read?

To flag an item, note its ID (for example PA-17) and what concerns you. Then open an issue on GitHub or send it to whoever shared this page with you.

This page is for reviewers, so it shows every answer. The practice site doesn't link to it.
